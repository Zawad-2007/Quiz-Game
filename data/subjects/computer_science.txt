# Multiple-Choice Questions for Computer Science

Q: Which data structure operates on a First-In-First-Out (FIFO) basis?
A: Stack
B: Queue
C: Binary Tree
D: Hash Map
Ans: B
Exp: A Queue processes elements in FIFO order, while a Stack uses LIFO.
---
Q: What is the average time complexity of searching in a balanced Binary Search Tree?
A: O(1)
B: O(n)
C: O(log n)
D: O(n log n)
Ans: C
Exp: Balanced BSTs halve the search space at each step, yielding O(log n).
---
Q: Which layer of the OSI model is responsible for end-to-end communication and port addressing?
A: Physical Layer
B: Network Layer
C: Transport Layer
D: Session Layer
Ans: C
Exp: Transport Layer (Layer 4) handles TCP/UDP and end-to-end reliability.
---
Q: What is the primary purpose of Virtual Memory in modern operating systems?
A: To speed up CPU clock rate
B: To allow processes to use more memory than physically available RAM
C: To replace SSDs completely
D: To encrypt files on disk
Ans: B
Exp: Virtual memory provides an illusion of contiguous large memory via paging.
---
Q: Which scheduling algorithm may suffer from the 'convoy effect'?
A: Round Robin (RR)
B: Shortest Job First (SJF)
C: First-Come, First-Served (FCFS)
D: Priority Scheduling
Ans: C
Exp: In FCFS, short processes get stuck waiting behind long CPU-bound processes.
---
Q: What is the binary representation of the decimal number 13?
A: 1100
B: 1101
C: 1011
D: 1110
Ans: B
Exp: 8 + 4 + 1 = 13, which is 1101 in binary.
---
Q: In relational databases, what does SQL stand for?
A: Standard Query Logic
B: Structured Query Language
C: Simple Question Language
D: Sequential Query List
Ans: B
Exp: SQL stands for Structured Query Language.
---
Q: Which algorithm design paradigm does Merge Sort use?
A: Greedy Approach
B: Dynamic Programming
C: Divide and Conquer
D: Backtracking
Ans: C
Exp: Merge Sort divides the array into halves, sorts recursively, and merges.
